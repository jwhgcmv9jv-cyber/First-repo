# AppLimiter — ограничение времени работы приложения (Windows 10/11)

Программа ограничивает время использования **одного** выбранного приложения
(например, `chrome.exe`, игра, `Telegram.exe`).

## Как это работает

| Что | Как |
|---|---|
| Учёт времени | Время тратится только пока приложение запущено. Сначала расходуются «бесплатные минуты в день» (можно поставить 0), остаток сбрасывается каждый день в полночь. |
| Время вышло | Приложение закрывается, а при попытке открыть — сразу закрывается снова. Появляется окно ввода кода. |
| Продление | Вводится **4-значный код доступа** → добавляется N минут (задаётся в настройках). |
| Смена кода | Код **одноразовый**: в том же окне обязательно задаётся новый 4-значный код (нельзя повторить старый). Старый код больше не работает. |
| Мастер-код | Задаётся один раз при установке (4–8 цифр). Нужен для настроек и **удаления** программы. |
| Защита от подбора | 5 неверных попыток → блокировка ввода на 5 минут. |

## Установка

1. Скачайте `AppLimiter.exe` со страницы **Releases** репозитория (тег `app-limiter-latest`)
   или из артефакта сборки в **Actions**.
2. Запустите (Windows попросит права администратора).
   SmartScreen может предупредить «неизвестный издатель» — «Подробнее» → «Выполнить в любом случае»
   (файл не подписан цифровой подписью).
3. В окне первой настройки:
   - выберите `.exe` приложения кнопкой «Обзор…» (или впишите имя, например `chrome.exe`);
   - бесплатные минуты в день и сколько минут даёт один ввод кода;
   - **мастер-код** (запомните — без него не удалить программу);
   - первый код доступа.
4. Значок-щит появится в области уведомлений рядом с часами.

Меню значка: «Ввести код (продлить время)», «Настройки (мастер-код)», «Удалить AppLimiter».

## Удаление

«Параметры → Приложения → Установленные приложения → AppLimiter → Удалить»
или меню значка → «Удалить AppLimiter…». Потребуется **мастер-код**.

## Устройство

- `AppLimiter.exe --service` — служба Windows (LocalSystem, автозапуск, перезапуск при сбое):
  считает время, закрывает приложение, проверяет коды.
- `AppLimiter.exe --tray` — значок в трее; служба сама запускает его в сеансе пользователя
  и перезапускает в течение 5 секунд, если его закрыли.
- Настройки: `C:\ProgramData\AppLimiter\config.json`, доступ только у SYSTEM и Администраторов.
  Коды хранятся только в виде хэшей (PBKDF2-SHA256).
- Приложение распознаётся по имени процесса, по полному пути и по «исходному имени файла»
  из свойств exe — переименованная копия тоже будет поймана.

## Важно знать (честно об ограничениях)

- Надёжно работает, если ребёнок/пользователь сидит под **обычной (не администраторской)
  учётной записью**. Администратор компьютера может остановить службу и обойти любую подобную программу.
- Ограничивается одно приложение. Веб-версии (например, игра в браузере) не учитываются,
  если не ограничен сам браузер.
- Если забыли код доступа — задайте новый в «Настройках» по мастер-коду.
  Если забыли мастер-код — удалить программу может только администратор вручную
  (`sc stop AppLimiter`, `sc delete AppLimiter`, удалить `C:\Program Files\AppLimiter`
  и `C:\ProgramData\AppLimiter`).

## Сборка вручную

Нужен .NET 8 SDK на Windows:

```
dotnet publish app-limiter/src/AppLimiter.csproj -c Release -o out
```

Получится один файл `out/AppLimiter.exe` (самодостаточный, .NET ставить не нужно).
