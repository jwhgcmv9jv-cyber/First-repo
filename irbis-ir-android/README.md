# Irbis ИК‑пульт для Android‑телефона с ИК‑портом

Приложение превращает телефон с ИК‑передатчиком (Xiaomi/Redmi/POCO, некоторые
Honor/Huawei/Realme) в пульт для интерактивной доски Irbis. Ни Wi‑Fi, ни
настроек на доске не нужно — как у обычного пульта.

## Установка
1. Скачайте `irbis-ir-remote.apk` со страницы **Releases** репозитория
   (релиз «Irbis ИК‑пульт (Android)») — или из артефактов последней сборки
   во вкладке **Actions**.
2. Откройте файл на телефоне → разрешите «Установку из неизвестных источников».
3. Запустите «Irbis ИК‑пульт», направьте верх телефона на доску.

Вверху экрана видно, есть ли в телефоне ИК‑передатчик.

## Коды
По умолчанию — коды из базы IrCode Finder (#500202, «IRBIS Promethean
Interactive Board»): протокол NEC, 38 кГц, адрес `0x807F`.

| Кнопка | Команда | Полный код |
|---|---|---|
| Питание | 18 | 0x807F18E7 |
| Источник | B0 | 0x807FB04F |
| Меню | 02 | 0x807F02FD |
| ▲ ▼ ◀ ▶ | 62 / 68 / E2 / A8 | 0x807F629D … |
| OK | AA | 0x807FAA55 |
| Громкость − / + | 08 / 28 | 0x807F08F7 / 0x807F28D7 |
| Стоп‑кадр | 48 | 0x807F48B7 |
| Пустой экран | 20 | 0x807F20DF |

**Эти коды не проверены на реальной доске.** Если доска не реагирует:
- «Подбор адреса» — перебирает 256 адресов NEC с выбранной командой
  (удобно «Громк. +»: на доске появится шкала);
- «Подбор команд» — перебирает 256 команд на найденном адресе, найденную
  можно назначить любой кнопке (так находятся «Домой», «Назад» и т.п.);
- «Коды кнопок» — ручной ввод.

Если пульт доски использует не NEC (например RC‑5/RC‑6), подбор не поможет.

## Сборка вручную
Android Studio → Open → папка `irbis-ir-android` → Build → Build APK.
