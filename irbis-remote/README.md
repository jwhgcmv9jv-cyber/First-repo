# Irbis Пульт — управление интерактивной панелью Irbis с iPad по Wi‑Fi

У iPad нет ИК‑передатчика, поэтому пульт работает **по сети**: iPad открывает
веб‑страницу в Safari, а небольшой сервер на Python передаёт команды панели.
Устанавливать что‑либо на iPad не нужно.

```
iPad (Safari) ──Wi‑Fi──► server.py ──► панель Irbis
                                       • Android панели — через ADB по сети
                                       • OPS‑компьютер (Windows) — эмуляция клавиатуры/мыши
```

## Что умеет
- **Пульт:** стрелки, OK, Назад, Домой, переключение окон, громкость ±/без звука,
  листание слайдов (PageUp/PageDown), Play/Pause, меню, источник, настройки, питание.
  Стрелки, громкость и слайды повторяются, если кнопку удерживать.
- **Тачпад:**
  - режим ADB: поле = уменьшенный экран панели (касание, свайп, долгое нажатие, прокрутка двумя пальцами);
  - режим OPS: тачпад как у ноутбука (курсор, клик, правый клик двумя пальцами, прокрутка, перетаскивание).
- **Текст:** набор на клавиатуре iPad и отправка на панель.
- PIN‑код для защиты от посторонних в сети.
- Добавляется на экран «Домой» iPad и открывается как приложение.

## Какой режим выбрать

| На панели работает…                         | Режим          | Где запускать server.py                                  |
|---------------------------------------------|----------------|----------------------------------------------------------|
| Встроенный Android                          | `--mode adb`   | Любой ПК/ноутбук/Raspberry Pi в той же сети, что панель   |
| Windows на OPS‑модуле (вставной компьютер)  | `--mode local` | Прямо на OPS‑компьютере панели                            |

Можно использовать оба одновременно (на разных портах).

---

## Режим 1: Android панели (ADB)

1. На панели включите режим разработчика: *Настройки → О устройстве* → 7 раз нажать
   «Номер сборки». Затем в *Для разработчиков* включите **Отладку по USB** и, если есть
   такой пункт, **Отладку по сети / ADB over network**.
2. Узнайте IP панели (*Настройки → Сеть*). Желательно закрепить его в роутере.
3. На компьютере установите [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)
   (чтобы команда `adb` была доступна) и Python 3.8+.
4. Запустите:
   ```bash
   python3 server.py --mode adb --board 192.168.1.50 --pin 1234
   ```
5. При первом подключении на экране панели появится запрос «Разрешить отладку?» —
   отметьте «Всегда разрешать» и нажмите OK.

**Если панель не слушает порт 5555** (в некоторых прошивках сетевой ADB выключен),
один раз подключите панель USB‑кабелем (порт USB‑B / Touch) к компьютеру и выполните:
```bash
adb tcpip 5555
```
После перезагрузки панели это может понадобиться повторить — зависит от прошивки.

## Режим 2: OPS‑компьютер (Windows)

1. Установите Python 3.8+ на OPS‑компьютер панели.
2. ```bash
   pip install -r requirements.txt
   python server.py --mode local --pin 1234
   ```
3. Разрешите Python в брандмауэре Windows (частные сети).
4. Для автозапуска положите ярлык на `pythonw server.py --mode local --pin 1234`
   в папку `shell:startup`.

## На iPad

1. iPad должен быть в **той же Wi‑Fi‑сети**, что сервер.
2. Откройте в Safari адрес, который сервер напечатал при запуске, например
   `http://192.168.1.20:8080/?pin=1234`.
3. «Поделиться» → **«На экран Домой»** — пульт будет открываться как приложение.

## Ограничения (по факту)
- Без ИК и без сети управлять панелью с iPad нельзя — нужна общая сеть.
- Если **Android панели выключен кнопкой питания** (глубокий сон/выключение), ADB по сети
  недоступен, включить панель так нельзя. «Питание» в режиме ADB переводит в сон/будит,
  пока панель на связи. Для включения «из выключенного» нужен RS‑232/LAN‑протокол
  управления (есть не во всех моделях Irbis — уточняйте в документации своей модели) или ИК.
- Ввод текста через ADB — только латиница, цифры и знаки (ограничение команды Android
  `input text`). В режиме OPS кириллица вводится через буфер обмена (`pyperclip`).
- Коды кнопок «Источник» (`KEYCODE_TV_INPUT`) и «Настройки» — стандартные коды Android;
  оболочка конкретной прошивки Irbis может их не обрабатывать.
- Трафик идёт по HTTP без шифрования. Используйте PIN и доверенную сеть;
  не открывайте порт в интернет.

## API (если нужно встроить в своё)
`GET /api/info`, `POST /api/key {"key":"vol_up"}`, `/api/tap {"x":0.5,"y":0.5}`,
`/api/swipe {"x1","y1","x2","y2","ms"}`, `/api/long {"x","y"}`, `/api/scroll {"dy"}`,
`/api/move {"dx","dy"}`, `/api/click {"button"}`, `/api/drag {"state":"down|up"}`,
`/api/text {"text"}`. Координаты нормированы 0…1. PIN — заголовок `X-Pin`.
